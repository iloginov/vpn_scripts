# Настройки параметров AmneziaWG

Старые версии протокола AmneziaWG стали резаться операторами.

Сейчас надо делать схему на AmneziaWG **3.1** (поверх 2.0 / 3.0).
См. [[awg3_protocol_params]].

Общая логика для настройки сервера в 2026 году — это правдоподобная мимикрия трафика под какой-то распространённый протокол.

Рекомендуется взять QUIC и порт 443. (Желательно, чтобы протокол и порт соответствовали друг-другу, но это не обязательно.)

Генерацию готовых конфигов с разными настройками типа мимикрии можно посмотреть тут: [https://github.com/Vadim-Khristenko/AmneziaWG-Architect](https://github.com/Vadim-Khristenko/AmneziaWG-Architect)

Общая логика параметров протокола AmneziaWG 2.0.


| Параметры    | Сервер        | Клиент     | Комментарий                                                                                                                                                                |
| ------------ | ------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| H1-H4        | Использует    | Использует | Обязаны совпадать у сервера и клиента                                                                                                                                      |
| S1-S4        | Использует    | Использует | Обязаны совпадать у сервера и клиента                                                                                                                                      |
| I1-I5        | Не использует | Использует | Сервер может хранить в конфиге эти параметры как шаблон для генерации клиентских конфигов. Клиент может сам менять эти параметры без каких-то действий на стороне сервера. |
| Jc/Jmin/Jmax | Не использует | Использует | Сервер может хранить в конфиге эти параметры как шаблон для генерации клиентских конфигов. Клиент может сам менять эти параметры без каких-то действий на стороне сервера. |


Полное описание протокола: [https://docs.amnezia.org/documentation/amnezia-wg/](https://docs.amnezia.org/documentation/amnezia-wg/)

Там перечислены ограничения на задание этих параметров:

- `S1 + 56 ≠ S2`
- `S4 ≤ 32`
- Диапазоны H1–H4 не пересекаются
- `Jmin < Jmax`

Якобы, в языке CPS есть ещё тэг `<c>` (номер текущего пакета), который то ли реализован, то ли нет:
